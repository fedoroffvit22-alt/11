# «Бизнес Маркет» — озвучка пилотов

Этап 3. Синтез речи: Yandex SpeechKit. Рассказчик — голос «Мадирус». Все файлы обрезаны по тишине и выровнены по громкости.

- Отдельные реплики: `assets/<серия>/golos/` — имя файла начинается с номера кадра.
- Черновая дорожка серии целиком (реплики расставлены по времени кадров, без музыки): `assets/<серия>/golos-chernovik.mp3`.
- Пробы голосов рассказчика: `assets/golos-proby/`.
- Скрипт синтеза: `scripts/tts-yandex.py`, тексты реплик: `scripts/voice-lines.json`.

Каждая фраза проверена обратным распознаванием речи. Интонацию и ударения распознавание не оценивает — их нужно проверить на слух.
