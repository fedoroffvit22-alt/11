# «Бизнес Маркет» — озвучка пилотов

Этап 3. Синтез речи: модель `gpt-4o-mini-tts` (OpenAI). Рассказчик — голос `onyx`, ускорен на 10 %. Все файлы обрезаны по тишине и выровнены по громкости.

- Отдельные реплики: `assets/<серия>/golos/` — имя файла начинается с номера кадра.
- Черновая дорожка серии целиком (реплики расставлены по времени кадров, без музыки): `assets/<серия>/golos-chernovik.mp3`.
- Пробы голоса рассказчика на одном тексте: `assets/golos-proby/` — `onyx`, `ash`, `echo`, `ballad`.

Каждая фраза проверена обратным распознаванием речи: текст совпадает со сценарием. Интонацию и ударения распознавание не оценивает — их нужно проверить на слух.
