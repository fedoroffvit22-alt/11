## Дизайн
- **Первый экран:** большое фото ЖК на весь экран, плавный параллакс. Поверх — панель «жидкое стекло» с ценой, ₽/м², «100 м до метро», кнопками. Стекло: `backdrop-filter: blur() saturate()`, тонкая светлая обводка, блик-градиент, лёгкое преломление (SVG-фильтр `feDisplacementMap`, где поддерживается), плюс фолбэк без blur.
- **Галерея:** полноэкранная, листается свайпом и стрелками, открывается на весь экран, с подписями и счётчиком.
- **Планировка:** настоящий план, если найдётся. Поверх — интерактивные зоны комнат с площадями. Если плана нет, оставь текущую SVG-схему.
- **Ремонт:** сравнение шторкой «white box ↔ пример ремонта» на фото шоурума или аналогичной планировки, с честной подписью.
- **Живость:** появление блоков при прокрутке, бегущая строка рынка, счётчики цифр, плавные переходы. Всё отключается при `prefers-reduced-motion`.
- **Сохранить из текущей версии:**
  - график «цена за м² по этажам»;
  - калькулятор сделки с переводом долга;
  - калькулятор аренды в сравнении со вкладом;
  - локацию и станции;
  - таблицу «апартамент, а не квартира»;
  - шаги сделки, FAQ;
  - список источников с датами;
  - форму, которая собирает сообщение для Telegram и WhatsApp.
- **Без «нейросетевых» штампов:**
  - без эмодзи, фиолетовых градиентов, одинаковых карточек с иконками;
  - без шрифта Inter и центрирования всего подряд;
  - без фраз вроде «откройте для себя», «идеальный выбор».
- **Тексты:** короткие, конкретные, от лица собственника, без указания пола.
- **Мобильная версия в приоритете:** покупатели смотрят с телефона. Нижняя панель «Позвонить / Написать».
