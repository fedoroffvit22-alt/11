# Титры и графика

Весь текст в фильме делается на монтаже, поверх сгенерированных кадров. Генераторы плохо пишут кириллицу, а графика на монтаже правится за минуту.

## Общий стиль

- **Шрифт титров:** PT Sans Narrow Bold (бесплатный, с кириллицей), заглавные, разрядка +5 %. Замена — Oswald SemiBold.
- **Печать «−11 000 000 ₽»:** Oswald Bold с текстурой штампа.
- **Экраны телефонов:** Inter (бесплатный, с кириллицей). Интерфейсы нейтральные: без цветов и логотипов настоящих мессенджеров и каршерингов.
- **Цвета:**
  - белый `#FFFFFF` — основной;
  - красный `#D7261E` — деньги в минус, печать, перечёркивания;
  - жёлтый `#F2B705` — цвет губки, только для «ПЛЮС КОЛПАКИ»;
  - подложка — чёрная, 60 % прозрачности, если фон светлый.
- **Размеры для 1080p:** титры героев — 96 px; карточки времени — 120 px; печать — 220 px; локация — 56 px.
- **Поля:** не ближе 5 % к краю кадра. Для будущей вертикальной версии важное держать в центральной трети.

**Анимация:**
- «Удар» (титры героев, карточки): масштаб 120 → 100 % за 4 кадра, размытие движения, звук З-11. Исчезает склейкой, без растворения.
- Печать: 140 → 100 % за 3 кадра, тряска всего кадра на 3 кадра, звук З-03.
- Титры героев стоят на стоп-кадре внизу слева, в две строки: имя крупно, глагол мельче.
