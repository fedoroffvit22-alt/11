# Покадровый план

## Как читать

- **Номер клипа** — сцена и клип: `04-02`. Под этим номером сохраняются файлы (`04-02_frame_v1.png`, `04-02_v1.mp4`).
- **Таймкод** — место клипа в готовом фильме. Генерировать с запасом 1–2 секунды.
- **Кадр** — запрос на стартовую картинку. **Движение** — запрос на оживление этой картинки.
- **Реплики** — номера из `voiceover.md`. «Липсинк» — губы нужно подогнать под записанную реплику.
- Подстановки `{GENA}`, `{STYLE}` и т. п. — из `characters.md` и `README.md`.

**Покрытие.** Сцены с диалогами (4, 8, 9, 10, 11, 12) собираются из одиночных планов: для каждого героя генерируется один длинный клип, где он говорит, и из него нарезаются все его реплики в сцене. Это дешевле и надёжнее, чем отдельный клип на каждую фразу. Под такими сценами — таблица раскладки по таймкодам. Двое говорящих в одном кадре не встречаются нигде.
