## Музыка

Своя, без узнаваемых треков и без подражания конкретным саундтрекам. Нужны: основная тема (около 80 с), тревожная версия, тёплая версия, финальная солнечная, отдельные медные удары и стабы, одна низкая нота виолончели.

Запрос, если музыку генерировать:

```
instrumental crime caper groove, dirty bass, breakbeat drums, punchy brass stabs, twangy surf guitar, 104 bpm, minor key, swagger, cinematic, no vocals
```

## Рецепты эффектов

**Стоп-кадр** (00:14, 00:24, 00:50, 01:29, 02:46; на 00:06 — вариант с печатью):
1. Остановить последний кадр клипа на время из таблицы.
2. За 2 кадра обесцветить на 60–70 %, за всё время стоп-кадра медленно наехать 100 → 104 %.
3. В момент остановки — белая вспышка на 2 кадра и звук З-11.
4. Титр — ударом (`graphics.md`). Выход — склейкой, без растворения.

**Перемотка** (00:08 и 01:59):
1. Взять предыдущие 2–4 секунды материала и проиграть задом наперёд, ускорив в 6–8 раз.
2. Поверх — помехи VHS: горизонтальные полосы, дрожание кадра, сдвиг цветовых каналов на 3–5 пикселей.
3. Звук З-04, длительность — от половины секунды до секунды.

**Рапид в перемотке** (02:00–02:02): клип 05-03 с цифровым наездом на задний план (примерно в 3 раза). Отмашка Гены — в половину скорости с дорисовкой промежуточных кадров, звук З-17. Если при увеличении картинка разваливается — запасные клипы 05-03з1 и 05-03з2.

| 2 (ночь), 3, 10-04б | Натриевый оранжевый, циан в тенях |

| 7 | У Артёма — холодный белый, у Гены — тёплый жёлтый, у Петровны — серый с тёплым светом из окна |
| 12 | Тёплое низкое солнце, насыщенность +15 %. Первый по-настоящему тёплый кадр фильма |

Клипы одной сцены выровнять по мастер-кадру локации: генераторы дают разный баланс белого даже в соседних клипах.

## Сведение

- Речь — главный приоритет: диалог около −16…−18 LUFS. Под речью музыка приглушается на 10–12 дБ.
- Итог — −14 LUFS интегрально, пик не выше −1 dBTP.
- Тишина на 00:00–00:01, 01:55–01:59 и 02:41–02:44 — без музыки, только фон двора, очень тихо.
- Рассказчик — сухой и близкий, без эха. Героям — немного пространства по локации: в Сити звонкое стекло, во дворе открытый воздух, в офисе тесно.

## Субтитры

Две версии фильма:
- основная — без субтитров;
- для лент соцсетей — с вшитыми субтитрами из `voiceover.md`: внизу по центру, PT Sans Narrow Bold 54 px, белые с чёрной обводкой 3 px, не больше двух строк. На стоп-кадрах с титрами героев поднимать субтитры выше титра.

## Экспорт

- Мастер: MP4 (H.264 High), 1920×1080, 24 кадра в секунду, 20 Мбит/с; звук AAC, 320 кбит/с, 48 кГц, стерео.
- Чистая версия без мата: заменить Р-01 по `voiceover.md`.
- Обложка: стоп-кадр 01-05 с печатью «−11 000 000 ₽» — тот же крючок, что в первые секунды фильма.

## Сборка через Claude Code

Когда клипы, реплики, музыка и шумы будут готовы и названы по правилам из `README.md`:
1. Сложить их в одну папку: `clips/`, `voice/`, `music/`, `sfx/`. Большие видеофайлы лучше не хранить в git — передать архивом или ссылкой.
2. Claude Code соберёт черновой монтаж по таблицам `shotlist.md`: обрезка клипов, стоп-кадры, перемотки, графика, звук.
3. Дальше — правки тайминга и цвета итерациями.
