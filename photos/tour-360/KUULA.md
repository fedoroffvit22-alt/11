# 360-тур в Kuula для Циана

Kuula (kuula.co) есть в списке партнёров Циана: ссылку на тур оттуда можно вставить в объявление.

## Файлы
Все панорамы в формате 2:1 (4096×2048), их можно загружать как есть.

| Файл | Где точка съёмки |
|---|---|
| `pano-1-kuhnya.jpg` | Кухня-столовая, между гарнитуром и столом |
| `pano-2-spalnya-16.jpg` | Спальня 16,4 м², у изножья кровати |
| `pano-3-komnata-13.jpg` | Комната 13,5 м², у изножья кровати |
| `pano-4-prihozhaya-vhod.jpg` | Прихожая у входной двери |
| `pano-5-prihozhaya-koridor.jpg` | Коридор у дверей комнат |
| `pano-6-sanuzel.jpg` | Санузел |

## Шаги
1. Зарегистрируйтесь на **kuula.co** (Sign up). Бесплатного тарифа хватит.
2. Нажмите **Upload** и загрузите все 6 файлов. Kuula сам распознает их как 360°.
3. Нажмите **Create → Tour** и добавьте в тур все 6 панорам. Первой поставьте `pano-4-prihozhaya-vhod`: тур начинается от входной двери.
4. В каждой панораме нажмите **Edit → Hotspots → Add → Link to post** и поставьте точку перехода на дверной проём:

| В панораме | Точка на | Ведёт в |
|---|---|---|
| Прихожая у входа | проход в глубину коридора | Коридор |
| Прихожая у входа | открытая дверь справа (кухня) | Кухня |
| Прихожая у входа | дверь справа ближе к входу | Санузел |
| Коридор | дверь вверх по коридору | Спальня 16,4 |
| Коридор | дверь справа | Комната 13,5 |
| Коридор | в сторону входа | Прихожая у входа |
| Кухня | открытая дверь в прихожую | Прихожая у входа |
| Спальня 16,4 | дверь в коридор | Коридор |
| Комната 13,5 | дверь в коридор | Коридор |
| Санузел | дверь | Прихожая у входа |

5. Для каждой панорамы выберите **Starting view**: развернуть кадр на окно или главную мебель и сохранить.
6. Нажмите **Publish**. В тексте тура напишите: «Визуализация отделки Greystone по ДДУ, лот 142, Аквилон Signal».
7. **Share → Copy link**. Ссылка будет вида `https://kuula.co/share/collection/…`.
8. В объявлении на Циане вставьте эту ссылку в поле **3D-тур**.
