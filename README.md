# Апартамент №142, «Аквилон Signal»: продажа переуступкой

- `docs/otsenka-i-strategiya.md` — оценка, рынок на ноябрь 2026 года, конкуренты, налоги, сценарии и план на 11 недель.
- `docs/obyavleniya-i-skript.md` — тексты объявлений, скрипт звонка, ответы на возражения.
- `landing/index.html` — лендинг одним файлом, без сборки. Все цифры с номером источника, список источников с датами внизу страницы. Данные лежат в блоке `<script>` с `LOT`, `SOURCES`, `DEV_LOTS`, `TICKER`. Откройте в браузере или выложите на любой хостинг (GitHub Pages, Netlify, Tilda «zero block» через HTML).

## Перед публикацией лендинга

В `landing/index.html` в блоке `const LOT = {...}` заменить:
- `phone`, `tg`, `wa` — контакты (сейчас заглушки);
- `devPrice` — цену аналога у застройщика после звонка в офис продаж;
- `price` и `priceMin` — при изменении цены по плану.
