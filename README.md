## Перед публикацией лендинга

В `landing/index.html` в блоке `const LOT = {...}` заменить:
- `name`, `phone`, `tg`, `wa` — контакты (стоят: Наталья Семенова, +7 925 856-46-02);
- `DEV_LOTS` — прайс застройщика (на 01.11.2026 в каталоге цена при 100% оплате со скидкой 25%, базовая — в поле `base`);
- `RENT_DEFAULT` — ставка аренды по умолчанию (сейчас допущение 80 тыс: Циан 01.11.2026 проверить не удалось);
- `price` и `priceMin` — при изменении цены по плану.
